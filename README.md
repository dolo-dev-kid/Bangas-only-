🎵 Bangas-Only

Bangas-Only is a modern online recording studio platform built for artists, producers, and engineers.

Users can:

- Record vocals directly in the browser
- Upload beats and stems
- Collaborate on projects
- Store sessions securely
- Chat with collaborators
- Export finished tracks
- Create artist profiles
- Manage recording projects

---

## 🚀 Features

### 🎙 Recording Studio
- Browser-based audio recording
- Microphone detection
- Multi-take recording
- Playback controls
- Track management

### 🎹 Beat Library
- Upload beats
- Organize by genre
- Favorite tracks
- Search functionality

### 👥 Collaboration
- Invite collaborators
- Shared projects
- Studio messaging
- Version history

### 📁 Cloud Storage
- Audio uploads
- Session backups
- Secure file management

### 🎚 Mixing Workspace
- Volume controls
- Pan controls
- Mute/Solo
- Basic mixing tools

### 💬 Community
- Artist profiles
- Producer profiles
- Follow system
- Community feed
